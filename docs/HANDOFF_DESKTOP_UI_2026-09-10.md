# 데스크톱 UI 단순화 인수인계 — 2026-09-10

이 문서는 2026-09-10 사용자와 추가로 합의한 **다음 빌드 UI/UX 방향**을 기록한다. 기존 `docs/HANDOFF.md`의 v0.4.0 상태와 모바일 요구사항을 대체하지 않으며, 이후 데스크톱 UI 개편 시 아래 결정을 최신 사용자 지시로 우선 적용한다.

## 1. 데스크톱 하단 메뉴를 왼쪽 사이드로 이동

현재 데스크톱 화면 하단에 있는 다음 3개 기능을 왼쪽 사이드 메뉴로 이동한다.

- 가구 추가
- 가구 편집
- 호실 치수 확인

목적은 하단 UI가 차지하는 세로 공간을 줄이고 도면 작업 영역을 넓히는 것이다. 데스크톱에서는 작업 도구가 한쪽에 모여 있는 구조가 더 자연스럽고, 도면 자체가 화면의 중심이 되도록 한다.

### 권장 구조

- 데스크톱: 왼쪽에 얇은 고정 세로 툴바.
- 필요할 때만 툴바 오른쪽으로 보조 패널이 펼쳐지는 구조.
- 툴바에는 `가구 추가 / 가구 편집 / 호실 치수 확인` 기능을 세로로 배치.
- 보조 패널을 닫으면 도면 영역이 최대한 넓어져야 한다.
- 오른쪽 영역은 향후 선택 가구의 상세 속성 등 확장 가능성을 남겨둔다.
- 기능 위치만 데스크톱에서 변경하고 기존 기능 의미나 데이터 구조를 불필요하게 바꾸지 않는다.

### 반응형 원칙

- 모바일은 현재의 하단 조작 구조를 유지한다.
- 데스크톱 브레이크포인트에서만 하단 메뉴를 왼쪽 사이드 메뉴로 전환한다.
- 데스크톱용 UI 개편 때문에 모바일 터치 흐름이나 v0.4.0의 모바일 동작이 깨지지 않도록 회귀 검증한다.

## 2. `선택 가구 편집`에서 X/Y 좌표 직접 입력 제거

선택 가구 편집 메뉴에 있는 **위치 X/Y 숫자 입력 기능은 제거한다.**

사용자 의도는 가구 위치를 숫자로 정밀 입력하는 CAD형 인터페이스보다, 도면 위에서 직접 드래그해 배치하는 단순하고 직관적인 흐름이다. X/Y 입력은 일반 사용자에게 복잡도만 높이므로 화면에서 제거한다.

구현 원칙:

- 가구 이동은 도면 위 드래그를 기본 조작으로 한다.
- 내부 모델의 x/y 좌표 데이터 자체는 유지한다.
- 저장/불러오기, 그룹 이동, 충돌 판정 등 내부 로직에서 좌표는 계속 사용한다.
- 제거 대상은 **사용자에게 노출된 직접 X/Y 입력 UI**다.
- 기존 코드가 선택 가구 편집 입력 필드와 좌표를 양방향 동기화하고 있다면, UI 제거 후 오래된 위젯 값이 드래그 위치를 다시 덮어쓰는 경로가 남지 않았는지 확인한다.

## 3. 사용자에게 보이는 숫자는 소수점 없이 정수 표시

사용자 UI에 표시되는 숫자는 원칙적으로 **소수점 자리를 표시하지 않는다.**

예:

- `1200.0 mm` → `1200 mm`
- `853.47 mm` → `853 mm` 또는 적용한 반올림 규칙에 따른 정수
- 가구 가로/세로/지름, 호실 치수, 회전값 등 사용자가 읽거나 입력하는 숫자는 가능한 한 정수 중심으로 통일

### 중요한 구현 원칙

표시를 정수화한다고 해서 내부 계산 정밀도를 낮추면 안 된다.

- 내부 좌표, 스케일, SVG 변환, 충돌/경계 판정 등은 기존 부동소수점 정밀도를 유지한다.
- 사용자에게 보여줄 때만 반올림/정수 포맷을 적용한다.
- 드래그·확대/축소를 반복할 때 정수화 때문에 누적 오차나 위치 튐이 생기지 않아야 한다.
- 저장 포맷은 기존 호환성을 깨뜨릴 이유가 없다면 내부 정밀값을 그대로 유지한다.
- 입력값은 가능하면 정수만 받도록 단순화하되, 기존 파일의 소수 좌표/치수가 존재해도 읽기 호환성을 깨지 않는다.

## 4. 이번 개편의 UX 기준

이번 변경의 핵심은 기능을 늘리는 것이 아니라 **복잡도를 줄이는 것**이다.

- 데스크톱에서 도면이 가장 넓고 중요한 작업 영역이어야 한다.
- 자주 쓰는 도구는 왼쪽 사이드에 모은다.
- 가구 위치는 직접 끌어서 조정한다.
- 일반 사용자가 이해할 필요 없는 좌표 입력은 숨긴다.
- mm 치수 등 사람이 읽는 값은 깔끔한 정수로 보여준다.
- CAD처럼 지나치게 전문적이고 복잡한 조작계를 지양한다.
- 기존 기능을 제거하거나 이동할 때 모바일 v0.4.0 동작, 저장 호환성, 그룹 이동, 호실 왕복 상태 유지가 깨지지 않도록 한다.
