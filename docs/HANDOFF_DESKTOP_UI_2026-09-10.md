# 데스크톱 UI 단순화 인수인계 — 2026-09-10

이 문서는 v0.4.0 이후 추가 합의한 다음 빌드 UI 방향이다. 최신 구현 결과는 `docs/HANDOFF.md` 최상단과 `CHANGELOG.md`를 함께 읽는다.

## 확정한 방향

- 데스크톱 하단의 `가구 추가 / 선택 가구 편집 / 호실 치수 확인`을 왼쪽 사이드 도구로 이동한다.
- 프로젝트 저장/불러오기는 본문 하단에 둔다.
- 선택 가구 편집의 X/Y 좌표 입력은 제거하고 위치는 도면 드래그로 조절한다.
- 사용자에게 보이는 가구·호실 치수와 점유율은 소수점 없는 정수로 표시한다.
- 내부 좌표, SVG 변환, 충돌 판정, 저장 파일은 부동소수점 정밀도와 v1/v2 호환성을 유지한다.
- 오른쪽에는 화면을 적게 차지하는 배치 가구 이름·개수 요약을 둔다.
- 모바일에서는 긴 하단 폼을 오가는 흐름 대신 상단 메뉴로 도구에 접근하고, 가구 탭 편집은 화면 하단 고정 시트로 제공한다.

## 품질 기준

- 도면을 클릭하거나 포커스해도 좌우 검은색·파란색 선이 나타나지 않는다.
- 가구 생성·이동·편집 재렌더와 모바일 주소창 높이 변화로 도면 축척이 바뀌지 않는다.
- 사이드바 폭이나 화면 방향처럼 실제 가용 너비가 바뀔 때만 다시 맞춘다.
- 호실 선택은 한 번의 선택으로 즉시 전환되고 사이드바 위에 별도 목록 레이어가 남지 않는다.
- 가구 길게 누르기는 작은 손떨림을 허용하며 드래그와 구분되고, × 터치는 뒤 도면으로 전달되지 않은 채 한 번만 삭제한다.

## 구현 결과

위 항목은 v0.5.0에서 반영했다. DOM 합성 이벤트 회귀 테스트는 통과했지만 iPhone Safari와 Android Chrome 실기기 확인은 계속 필요하다.
